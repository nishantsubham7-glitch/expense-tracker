# Expense Tracker 💰

A user-friendly Expense Tracker application designed to help you monitor your daily spending, categorize expenses, and stay on top of your budget.

## ✨ Features
- **Add Transactions:** Easily log daily income and expenses with titles and amounts.
- **Expense Categorization:** Organize spending into categories like Food, Travel, Bills, and Shopping.
- **Balance Summary:** Automatically calculates total balance, income, and expenses.
- **Clean Interface:** Simple and responsive design for quick tracking.

## 🚀 How to Use
1. Clone or download this repository to your local machine.
2. Open the project folder in your code editor (e.g., VS Code).
